# 学生项目评价

> 已确认：Core 完成且总分达到 60 分为培训完成，85 分为优秀；人才库和留用判断独立记录。

统一评价结构如下：

| 维度 | 分值 | 重点 |
|---|---:|---|
| Core 完成 | 40 | 主功能、主实验或主复现可运行 |
| 验证与可重复性 | 25 | 测试、参数、运行入口和证据 |
| 工程记录 | 20 | 结构、Git、文档和已知问题 |
| 现场说明与复盘 | 15 | 能解释决策、失败和下一步 |

Core 是独立门槛：总分较高但主流程没有完成时，只能记录为部分完成。截图只能辅助说明，不能替代代码、测试、运行记录和现场解释。

## 结果分层

- `Core 完成 + 总分 >= 60`：培训完成；
- `Core 完成 + 总分 >= 85`：优秀；
- 其他情况：记录为部分完成，并写明下一步补救任务；
- 人才库、留用或后续岗位判断单独记录，不从本表自动推导。
