# M03：强化学习控制实验

## 定位

- 等级：中级
- 推荐周期：一月起步；两月更合适
- 适合：已经理解基本机器学习概念，并且能阅读训练曲线的学生
- 主线：环境、策略、奖励、训练稳定性和评估

## 背景

使用标准、可重复的模拟环境，例如 CartPole。项目不连接真实设备，也不要求学生花大量时间配置复杂仿真平台。

## Starter code

```text
src/
├── env_wrapper.py
├── agent.py
├── train.py
├── evaluate.py
└── plot.py
configs/base.yaml
tests/test_env.py
```

一周项目应提供基础 Agent；学生重点完成参数、奖励或策略的一处改动。

## 学生完成的核心代码

- 运行 baseline；
- 实现或补全一个基础策略；
- 进行一次受控实验；
- 记录多回合评估结果；
- 分析训练不稳定或失败原因。

## Core 验收

1. 环境和训练流程可以重复运行；
2. 固定随机种子和评估回合数；
3. 有 baseline 与改动后的结果对比；
4. 不用一次偶然的高分证明算法有效；
5. 能解释状态、动作、奖励和终止条件；
6. 报告包含训练曲线和失败案例。

## 必交材料

- Agent 和训练代码；
- 配置文件；
- 多回合评估结果；
- 训练曲线；
- 失败原因分析。

## Stretch

- 比较两种奖励设计；
- 比较两组探索参数；
- 设计一个新的简单环境约束。

## 周期扩展

- 一周：使用给定 Agent 完成一次受控实验；
- 一月：完成 baseline、改动和报告；
- 两月：比较两种策略或环境设置；
- 半年：形成明确研究假设并进行多轮实验。
