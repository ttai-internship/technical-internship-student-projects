# B02：数据清洗与报告

## 定位

- 等级：初级
- 推荐周期：一周；一月可增加数据质量规则
- 适合：编程基础一般，但对数据整理、表格和结果展示感兴趣的学生
- 主线：文件处理 + 条件判断 + 数据质量 + 可重复运行

## 背景

starter repository 提供一份脱敏 CSV/JSON 数据和预期报告样例。学生需要把原始数据转成可检查的清洁数据和汇总报告。

## Starter code

```text
data/
├── raw/sample.csv
└── expected/summary.json
src/
├── reader.py
├── validator.py
├── cleaner.py
├── report.py
└── main.py
tests/
└── test_pipeline.py
```

项目提供数据字段说明、若干错误样本、运行入口和基本测试。

## 学生完成的核心代码

- 读取 CSV/JSON；
- 检查缺失值、重复值和非法格式；
- 按规定规则清洗数据；
- 输出清洁数据和 Markdown/JSON 汇总报告；
- 为至少三条规则编写测试。

## Core 验收

1. 给定样例数据后，清洁记录数和汇总数与预期一致；
2. 重复记录按照说明处理；
3. 非法记录被记录或跳过，程序不会无提示退出；
4. 同一份输入重复运行可以得到相同结果；
5. 输出结果包含数据量、异常数量和主要统计项；
6. 测试和 CI 通过；
7. README 写清楚清洗规则，而不是只提交结果文件。

## 必交材料

- 清洗脚本；
- 测试；
- 清洁数据或报告样例；
- 数据质量问题清单；
- 运行命令和结果。

## Stretch

- 增加配置文件，让清洗规则不写死在代码中；
- 增加一张简单图表；
- 设计一个新的数据质量检查规则。

## 周期扩展

- 一周：完成固定规则和报告；
- 一月：增加可配置规则、图表和数据质量总结；
- 两月以上：可以加入简单数据服务接口，但不要求模型或复杂算法。

## 同步节点

主要检查学生是否理解数据规则，以及结果是否可重复，不需要逐行讲解代码。
