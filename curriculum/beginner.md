# 初级路线学习材料

> 状态：v0.1 草案。初级路线不要求算法题、机器学习或 AI；学习内容服务于 B01、B02、B03 三选一的基础工程实践。

## 学习重点

1. 基础 Python、模块拆分、输入校验和文件读写；
2. 常见数据结构与简单复杂度意识；
3. Git、commit、测试和基本 CI；
4. 用简单的系统设计图说明输入、处理、存储和输出。

## 推荐材料映射

| 学习目标 | 优先材料 | 对应实践 |
|---|---|---|
| 计算机和编程基础 | 楚国刮大风的基础编程、计算机原理和 coding 内容 | B01 命令行任务清单 |
| 建立数学和结构直觉 | 3Blue1Brown 的基础数学可视化内容，按兴趣选用 | B02 数据清洗与报告 |
| 理解技术产品和问题背景 | 张小珺商业访谈录或硅谷 101，选择 1 期 | B03 Web 功能切片 |

## 推荐的学习记录

学生不需要提交完整课程笔记，只需记录一个概念如何帮助自己完成项目中的一个设计决定。例如：为什么把输入校验放在边界层、为什么把存储接口单独拆出来、为什么一个 commit 应只表达一个意图。

## 级别边界

- 没有完成数学或 AI 材料，不影响初级项目的 Core 验收；
- 初级项目的主要证据仍然是可运行代码、测试、commit、运行日志和现场说明；
- 课程内容具体章节后续再补入，当前不绑定固定视频编号。
